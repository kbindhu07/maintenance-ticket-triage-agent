Pipeline

Ticket text + asset type→Clean text, extract asset IDs→ TF-IDF + Logistic Regression → category + confidence→ Low confidence? → keyword rules second opinion→ Rule-based severity (+ ML can only raise it)→ Root cause lookup + similar tickets→ Route: team, priority, SLA, actions→ Critical → escalation→Summary (LLM optional, template fallback)

What is ML, what is rules, what is GenAI

  • ML: category classifier (TF-IDF word + character n-grams, Logistic Regression) and a secondary severity model used only to raise severity.
  • Rules / tools: severity scoring, asset-consistency check, root-cause ranking, routing, SLA, escalation. These are deterministic and auditable.
  • GenAI (optional): writes a 2-3 sentence operator summary from the already-computed facts. It never decides category, severity or routing. Without an API key a template summary is used.
  • Agent: a deterministic tool-calling workflow with explicit decisions (confidence gate, consistency check, escalation). It is not an autonomous LLM agent. No RAG: the "similar tickets" step is a TF-IDF nearest-neighbour lookup used as supporting evidence.
